## 단계를 밟을 때

부장님이 어느 단계를 시작하실 때 Claude에게 **단계 번호만** 말하면 된다. 예:

> "설계서 §9 1.3 시작" → Claude가 그 단계의 **할 일 · 파일 · 검증 조건 · 앞서 끝나야 할 것**을 짚고 시작한다.
> "메신저 W3" → `메신저-설계.md` §6의 W3(FCM 푸시 · 봇 계정)로 같은 방식.

각 단계는 **검증 조건이 되면 다음**으로 간다. 안 되면 다음으로 가지 않는다.
