### 표 중심 5권 — 그냥 넣으면 **위험하다** (II part A-1·A-2·B·C·D, 5,611쪽)
`Table 1A` 를 그대로 텍스트로 뽑으면 행 구조가 깨져 숫자만 세로로 늘어선다:
```
1 / 275 / 140 / NP / NP / 343 / NP / CS–6
```
여기서 `343` 은 **최고사용온도**지 허용응력이 아니고, 재료 규격명은 아예 이 쪽에 없다.
압력용기 회사에서 AI 가 이런 조각을 근거로 허용응력을 답하면 설계가 틀린다.

**해법 — Line No. 로 이어 붙인다.** Table 1A 는 세 쪽에 걸쳐 있고 `Line No.` 가 공통 열쇠다:
- 58쪽: Line No. + 재료 식별(조성·제품형태·**Spec. No.**·Type/Grade·P-No.)
- 59쪽: Line No. + 인장/항복강도 + 섹션별 최고온도 + 외압챠트번호
- 60쪽: Line No. + **온도별 허용응력 값**

세 쪽을 Line No. 로 join 하면 한 줄이 완성된다("SA-516 Gr.70 / 판재 / 인장 485 / 40°C 138 MPa").
조각 하나가 재료명부터 숫자까지 다 갖게 되므로 위험이 사라진다.
- `page.find_tables()` 는 **못 쓴다** — ASME 표는 괘선이 없어 1행 2열로 뭉개진다(확인함).
- 다행히 `page.get_text()` 가 **줄 순서를 지켜서** 뽑아 준다. 좌표까지 갈 필요 없다.
- ⚠️ **이어 붙인 결과를 쪽 이미지와 표본 대조해 눈으로 확인한 뒤에만** 올린다. 열이 하나 밀리면 전부 틀린다.
- 규격번호 대시는 하이픈이 아니라 **엔대시**(`SA–516`)다. `startswith("SA-")` 로 찾으면 0건 나온다.

## 그림 — 된다 (확인함)
- 그림은 페이지에 **삽입 이미지**로 박혀 있다(`page.get_images()`). 벡터가 아니다.
- 원본 해상도가 크다(예: Figure UG-28 이 6590×2971).
- ⚠️ `extract_image()` 로 꺼내면 **색이 반전**된다(1비트 마스크 때문). 그대로 쓰면 검은 바탕이 된다.
- **해법**: `page.get_pixmap(dpi=170, clip=박스)` 로 쪽에서 오려낸다. 캡션까지 같이 나오고 색도 정상이다.
  박스는 `page.get_image_bbox()` 들과 `page.search_for("Figure UG-28")` 을 합쳐서 잡는다.

## 표 복원 — 완료 (2026-09-19 오전)

### Section II-D 허용응력표 → 재료 2,414개
`tools/asme-2d-tables.py`. Table 1A(철강) 1,391줄 · Table 1B(비철) 1,023줄. 버린 줄 3~4%(전부 세어서 보고).
- **Line No. 로 세 쪽(A 재료식별 / B 강도·온도한계 / C 온도별 응력)을 이어 붙인다.** 쪽 묶음은 A,B,C,C.
- **Line No. 는 쪽 묶음마다 1 로 다시 시작한다** — 열쇠에 쪽 번호를 넣지 않으면 뒤 묶음이 앞을 덮어쓴다.
- 표마다 열 구성이 다르다: 1A 는 A 10칸·B 9칸, **1B 는 두께·P-No. 가 B쪽으로 가서 A 7칸·B 11칸**.
- **줄 순서로 읽으면 안 된다** — `get_text()` 가 가까운 두 칸을 한 줄로 붙인다("K01700 …").
- **낱말 하나씩 왼쪽 x 로 넣어도 안 된다** — 가운데 맞춤된 넓은 칸이 왼쪽 열을 침범한다.
  p.59 3번 줄 "343 (Cl. 3 only)"(Section III)이 Section I 로 새어 `I = NP 343 (Cl.` 이 됐다.
  → 칸으로 묶어 **겹침이 가장 큰 열**에 넣는다.
- 칸 **찾기**는 넉넉한 간격(8), 칸 **나누기**는 좁은 간격(5). 쓰임이 반대다.
  5 는 실측값(칸 안 낱말 사이 2.5, 칸 사이 최소 6.9). 8 로 나누면 1B 의 "NP" 가 옆 칸에 먹힌다.

### Sec.II-D 표 여섯 개 전부
1A 1,391 · 1B 1,023 · 2A 564 · 2B 156 · 5A 256 · 5B 117.
표마다 열 구성이 다르다(1A A10/B9 · 1B A7/B11 · 2A A9/B7 · 5A A10/B6 · 5B A7/B8) →
**머리글을 읽어 이름을 짠다.** 순서가 중요하다: **열을 먼저 있는 그대로 세고, 그 수에 맞춰 이름을 짠다.**
거꾸로 하면(이름 먼저) 열맞추기가 그 수에 맞는 열을 억지로 만들어 내서 **값은 맞는데 이름이 틀린다** —
2A 에서 실제로 III·VIII-2 열에 1A 기준 이름(VIII-1)이 붙었다. Div.1 과 Div.2 는 다른 코드다.
머리글에서 섹션 이름을 못 읽으면 번호로 대충 붙이지 않고 **쪽을 버린다.**
조각에 **"쓰임" 줄**을 넣었다 — 1A/1B=Div.1 최대허용응력 S, 2A/2B=Div.1 Class1 설계응력강도 Sm,
5A/5B=Div.2 Class 2. 값의 정의가 달라서 안 적으면 엉뚱한 값이 답으로 나간다.

### 검색이 규격·등급을 가리게 했다
뜻 검색만으로는 SA-516 과 SA-350 을, 나아가 **같은 SA-516 안에서 Gr.65 와 Gr.70 을** 구분하지 못한다.
Gr.65 와 Gr.70 은 허용응력이 20% 넘게 다르다 — 그대로 쓰면 두께가 틀린다.
→ 질문에서 규격·조항 번호와 **"규격/등급" 한 덩이**(SA-516/70)를 뽑아 그 글자가 든 조각에 0.15 가산.
맨 숫자(70)를 쓰면 온도·응력 숫자에 죄다 걸려 무의미하다. 우리 조각이 "재료: SA-516 / 70 / …" 로
적으므로 공백·대시를 지우면 그대로 맞는다.
후보 풀은 넉넉히(4,000) 잡는다 — 76개만 보다가 정답이 순수 유사도 76등 밖이라 가산을 못 받은 적이 있다.
