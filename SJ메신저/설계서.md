## 2. 자료 등급 — 시스템이 아니라 자료를 나눈다

| 등급 | 무엇 | 저장 | 밖에서 접근 | 색인 |
|---|---|---|---|---|
| **A · 사외 가능** | 영수증 · 작업보고 · 작업허가서 · 현장 사진 · 비제한 도면 | **Cloudflare R2** (무제한 · 전송 0원) | 터널(기존) | Vectorize(기존) |
| **B · 반출 금지** | 제한 고객 도면과 마크업 | **시놀로지 그대로** — 건드리지 않음 | **노드 B 게이트 + 테일스케일**(단대단) | **노드 B 로컬 색인** — 벡터도 밖에 두지 않음 |

- 등급은 **고객·프로젝트 단위로 태깅**(`projects.dataGrade`). B는 어떤 경로로도 클라우드에 올라가지 않는다 — 코드가 아니라 rules와 게이트가 막는다
- B등급 열람은 **전부 기록**(누가·언제·어느 도면). 비밀유지계약서만 있는 경우 의무는 "합리적 보호조치"이고, 전송·저장 암호화 + 접근통제 + 열람기록이 그 답이다. 터널은 엣지에서 TLS가 한 번 풀리므로 B등급은 **테일스케일**(단대단)로만 — "제3자가 평문을 본 적 없다"고 말할 수 있는 구성
- B등급 **메타데이터**(도면명·프로젝트명)를 Firestore에 두는 것까지 금지인지는 고객별 문구 확인

## 5. AI 두뇌 — 3단 라우팅 + 노드 설계

### 3단 라우팅 (게이트웨이가 판단)

| 단 | 일 | 모델 | 어디 |
|---|---|---|---|
| 1 | 의도 분류 · 한 줄→JSON · 카드 초안 | 8~14B (Groq / 노드 A) | A등급은 Groq 우선 · B등급은 노드 A |
| 2 | 긴 문서 요약 · RAG 합성 · OCR 정리 | **27~32B** (노드 A) / Gemini Flash | B등급은 노드 A만 |
| 3 | 판단 · 복잡 질의 | Claude(A등급) / 70B(B등급 — 노드 C) | 사람이 요청할 때만 |

실패하면 멈추지 않는다 — **빈 카드로 사람에게**(05).

### 지금 모델로 되는 것 / 안 되는 것

| 일 | 필요 | 지금(gemma 12B · qwen 2B · bge-m3) |
|---|---|---|
| 1단 파싱 | 8~14B | **충분** |
| RAG 합성(한국어 기술문서) | 27~32B | 부족 → 노드 A |
| 문서 임베딩 | bge-m3 | **충분**(207만 장 실증) |
| DWG 색인 | 파일명·경로 | **이미 됨** (내부 내용 읽기는 P3 선택) |
| 도면 내부 이해 | VL 7~32B | 없음 → P3 선택 |
| 녹취 | whisper turbo | **충분** |

### Apple Silicon에서 램보다 먼저 볼 것
- **대역폭 = 토큰 속도**: M4 120GB/s → M4 Pro 273 → M4 Max 546 → Ultra 819
- **prefill(긴 입력 읽기)이 NVIDIA의 1/5~1/10** — RAG 체감 지연은 여기서 나오고 **Ultra를 사도 안 풀린다.** 그래서 "큰 한 대"보다 **역할별 두 대**

### 노드 설계 (P2 운영, 실험대와 분리)

```
노드 A 「대화」   1단 파싱 + RAG 합성(32B)                 ← 대역폭 · 항상 켜짐 · 지연 민감
노드 B 「색인」   bge-m3 · OCR · whisper · (VL) · B등급 게이트 · 로컬 색인 · NAS 야간동기   ← 처리량 · 밤에 바쁨
노드 C 「큰모델」 70B (B등급 고난도)                        ← P3 · 실측이 요구할 때만
```
게이트웨이가 모델 이름으로 노드를 고른다(9Router가 이미 하는 일). 노드끼리 TB5 브릿지, 시놀로지와 10GbE.

### 장비 로드맵

| 시기 | 항목 | 스펙 · 담는 것 | 비용(추정) | 트리거 |
|---|---|---|---|---|

| P1 | Cloudflare Workers Paid + **R2** | A등급 저장 | $5/월 + 저장량 | 영수증 스킬 착수 |

내구성: 원본은 시놀로지, 노드는 문·캐시·계산. 노드가 죽어도 잃는 건 그날 미동기 마크업뿐 → RAID 없이 UPS + 야간 동기.

## 7. 플랫폼 연동 계약

1. 같은 Firebase 프로젝트 · 같은 `users`(dept·grade) · 같은 `projects`(+`dataGrade`)
2. 스킬별 컬렉션: `t_workReports` · `t_expenses`(entries 이관) · `t_permits` — 기존 페이지가 읽는다
3. 딥링크: 확인 카드 → `index.html?module=…&id=…`
4. RAG: A등급은 `/rag/search`·`/rag/record`(Vectorize). **B등급은 노드 B 로컬 색인**만
5. 권한: `firestore.rules`에 `users.dept` 게이트. 민감 컬렉션은 본인 + 부서장 + super. **두 번째 부서가 민감 데이터를 올리기 전에**
6. **B등급 도면 게이트**(노드 B): Firebase 토큰 검증 → 마운트된 시놀로지에서 읽기 → 감사로그 `t_drawingAccess` → 테일스케일 경로만. 쓰기(마크업·현장사진)는 노드 B 로컬 → 야간 `nas-sync`
7. 외부 계정(`hkaiedu@naver.com`)이 사내 직원과 같은 권한 — 8개 부서 데이터 전에 의식적 결정
