# 압력용기 계산 도구 (pvcalc)

압력용기 계산 툴킷. 견적, 사전 검토, 상용 소프트웨어(PV Elite 등) 결과
교차검증 용도로 만든 사내용 파이썬 패키지 + 웹 도구입니다.

## 인허가 기준별 구성

웹 화면 최상단에서 근거 기준을 고릅니다. 같은 용기라도 기준이 다르면
허용응력·안전율·이음효율이 달라지므로, 선택한 기준이 계산서 머리에 찍힙니다.

| 기준 | 상태 | 근거 |
|---|---|---|
| **ASME VIII-1** | 구현 완료 | ASME BPVC Sec VIII Div.1 (+ Div.2 4.4/4.15) |
| **한국에너지공단** | **동체·경판 구현** | 열사용기자재 · KEA CODE Section IV (KPM-3210/3221/3222/3321/3323) |
| 산업안전 KOSHA | 구조만 (준비중) | 산업안전보건법 안전인증·안전검사 |
| **가스안전공사 KGS** | **동체·경판 구현** | KGS AC111 (2023) 3.3.1.1.1 / 3.3.1.1.3 / 3.3.1.1.4 |
| **API 650** | **셸 단별 두께 구현** | 5.6.3 1-Foot Method + **5.6.4 변동설계점법** + 5.6.1.1 |
| API 620 | 구조만 (준비중) | 저압 저장탱크 (약 15 psi 이하) |
| 위험물안전관리법 | 구조만 (준비중) | 옥외탱크저장소 (소방청) — API 650 의 국내 대응 |

아이템 종류도 함께 고릅니다 — 압력용기 · 열교환기 · Condenser · 저장탱크 ·
고압가스 저장탱크 · 특정설비. (기준, 아이템) 조합이 보이는 탭을 결정합니다.
열교환기·Condenser 는 동체·경판·노즐이 압력용기와 동일한 규칙이라 ASME 탭을
그대로 재사용하고, 추가로 필요한 UHX 튜브시트·TEMA 만 미구현으로 표시합니다.

> ⚠ **ASME 계산 결과를 국내 인허가에 그대로 제출할 수 없습니다.**
> 국내 기준 3종은 **원문을 확보한 뒤** 구현합니다 — 수식을 추정해 채우면
> "값은 나오는데 틀린" 계산서가 되므로, 각 탭에 필요한 원문을 적어 두었습니다.
> 무엇이 필요한지는 웹의 해당 탭에서 확인하실 수 있습니다.

> ⚠️ **본 계산 결과는 검증된 코드 계산서를 대체하지 않습니다.**
> 납품·인허가용 계산서는 반드시 PV Elite 등 검증된 소프트웨어 또는
> 수계산 검토를 거쳐야 합니다.

## 사용법

```bash
# 검증 테스트 실행
python tests/run_tests.py

# 예시 계산서 생성 (examples/output_calcnote.txt 저장)
python examples/example_vessel.py
```

파이썬에서 직접:

```python
from pvcalc import cylinder_thickness

r = cylinder_thickness(P=1.0, R=1003.0, S=138.0, E=1.0, CA=3.0)  # mm, MPa
print(r.report())            # 계산서 전체 출력
print(r.results["t_req_ca"]) # 부식여유 포함 필요두께
```

단위는 **일관된 한 벌**(SI: mm·MPa 권장, 또는 US: in·psi)을 사용하면 됩니다.
단, `ug45_neck_thickness`는 `units="SI"|"US"` 지정이 필요합니다(배관 표준
두께표·UG-16 최소두께 때문).

## 웹 버전 (단독 실행판)

`web/` 폴더 두 파일(`index.html`, `pvcalc-core.js`)이 전부입니다.
외부 CDN·폰트·서버 의존성이 없어 아래 어떤 방식으로도 배포 가능합니다.

- Firebase Hosting 등 정적 호스팅에 `web/` 폴더 업로드
- 기존 플랫폼 페이지에 `<iframe src=".../web/index.html">` 삽입
- 사내망 파일서버/공유폴더에서 직접 열기 (오프라인 동작)

계산 엔진(`pvcalc-core.js`)은 파이썬 엔진의 1:1 포팅이며, 두 엔진의 일치는
`python tests/gen_test_vectors.py && node web/test_core.mjs`로 자동 검증됩니다
(199 벡터 · 1081 비교 · 상대오차 1e-9 이내). **파이썬 수식을 수정하면 반드시
이 두 명령을 다시 돌려 JS 쪽 동기화를 확인할 것.**

### 재료 데이터 (선택 기능)

응력값을 매번 타이핑하지 않으려면 회사 licensed Sec II-D 사본의 값을 미리
넣어 두면 됩니다. 응력 입력 칸마다 재료 드롭다운이 생기고, 상단 설계온도로
**선형보간**해 채웁니다. 데이터가 없으면 전부 수동 입력(배포 기본 상태).

**입력 방법** — 웹의 **「재료 데이터 관리」 탭**에서 표로 직접 입력합니다.
재료별로 온도 행을 추가하고 S·Sy·Ey를 채운 뒤 저장하면 즉시 반영됩니다.

**저장 위치**

| 우선순위 | 위치 | 용도 |
|---|---|---|
| 1 | 브라우저 저장 (localStorage) | 관리 탭에서 입력한 값. 이 브라우저 전용 |
| 2 | `web/materials.js` | 배포 시 동봉하는 공용 값. 관리 탭에서 내보내기로 생성 |

브라우저 저장이 있으면 그쪽이 이깁니다. 「이 브라우저 저장 삭제」를 누르면
`materials.js` 값으로 돌아갑니다. 현재 활성 출처는 상단 파란 띠에 표시됩니다.

세종플랫폼 탑재 시 Firestore 저장으로 바꾸려면 `web/index.html`의 `matStore`
객체(load/save/clear 3개 함수)만 교체하면 됩니다 — 나머지 코드는 손대지 않아도
됩니다. 단 `load`가 async가 되므로 `initMaterials` 호출부에 `await`가 필요합니다.

**안전장치 (의도적으로 넣은 제약)**

- **데이터는 저장소에 커밋되지 않습니다.** `web/materials.js`는 gitignore,
  브라우저 저장은 애초에 파일이 아님. 저작권 자료가 GitHub·공개 호스팅에
  올라가지 않습니다.
- **판·출처 표기는 필수**이며 **모든 계산서 머리에 찍힙니다.** 판이 바뀌었는데
  데이터가 그대로면 바로 보이게 하는 장치입니다.
- 데이터 범위 밖 온도는 **외삽하지 않고 거부**합니다 — 조용히 틀린 값을 내는
  것보다 안 나오는 게 안전하므로.
- 저장 시 온도 자동 오름차순 정렬, 중복 온도·빈 온도·이름 없는 재료 거부.
- 각주(온도 제한 등)는 **해석하지 않습니다.** 재료명·비고에 적어 두고 사람이
  판단해야 합니다. 두께구간·제품형태별로 S가 다르므로 **항목을 나눠서** 입력할 것.
- 개스킷 m·y(App.2 Table 2-5.1)는 온도 무관이라 이 표에 없습니다 — 플랜지 탭에서
  직접 입력.

## 사용자가 직접 입력해야 하는 값 (저작권상 DB 내장 불가)

1. **허용응력 S** — ASME Sec II-D Table 1A/1B (설계온도 기준)
2. **항복강도 Sy, 탄성계수 Ey** — Sec II-D Table Y-1 / TM (외압 계산용)
3. 이음효율 E — UW-12
4. **개스킷 계수 m, 최소 착좌응력 y** — App.2 Table 2-5.1 (플랜지 계산용)
5. 볼트 허용응력 Sb·Sa, 플랜지 허용응력 Sf·Sfa — Sec II-D

## 범위 제한 (PV Elite와 다른 점)

- 외압은 UG-28 차트 대신 **VIII-2 4.4 수식**을 사용 → PV Elite(차트 기반)와
  수 % 차이가 날 수 있음. 대조표에서 확인할 것.
- **UG-41 용접부 강도는 부분 구현**입니다 (`weld_strength`):
  - 포함 — 개별 용접부 강도. UW-15(c) 계수(그루브 인장 0.74·그루브 전단 0.60·
    필릿 전단 0.49·노즐벽 전단 0.70) × `π/2·D·치수` 면적. 접합 두 재질 중
    약한 쪽 허용응력 적용. UW-15(b)(1)·외압 면제 처리.
  - 미포함 — **Fig. UG-41.1 경로별(1-1/2-2/3-3) 대조**. 경로에 어느 요소가
    속하는지는 적용 스케치에 따라 달라지므로 추정하지 않았습니다. 대신
    「전체 용접부 강도 합 ≥ 최대 용접하중」이라는 **필요조건만** 확인합니다
    (과소 용접은 걸러내지만 코드 검토를 대체하지 않음).
  - ⚠ W·W1-1·W2-2·W3-3 하중값은 공개된 UG-41(b)(1) 식을 그대로 구현했으나
    상용 SW(COMPRESS) 데모 리포트와 재현되지 않았습니다 (W가 약 10% 높고,
    W1-1/W2-2의 면적 조합이 상호 모순). **코드북 대조 전까지 참고값**으로만
    사용하십시오. 개별 용접부 강도는 이 문제와 무관합니다.
    확인 항목은 `comparison/UG41_verification.md`에 정리해 두었습니다.
- **플랜지(App.2)는 부분 구현**입니다:
  - 포함 — 인테그럴형(Fig.2-4 스케치 1~4c)과 허브 없는 루즈형(링 플랜지).
    App.2-5 볼트하중·유효 개스킷폭, 2-6 모멘트, 2-7 응력, 2-8 허용치.
    Table 2-7.1의 F·V·f는 37개 상수 닫힌형으로 계산하며, 직선 허브(A=0)에서
    공표값 F=0.908920·V=0.550103을 **6자리까지 재현**합니다.
  - 미포함 — **허브 있는 루즈형**(Table 2-7.1의 F_L·V_L을 앵커로 검증할 수
    없어 제외), 전면 개스킷(App.2-3), 분할 플랜지(2-6(g)), 외압(2-11),
    강성지수(2-14), 리버스 플랜지(2-13), 볼트 간격/PCC-1, 외부 배관하중,
