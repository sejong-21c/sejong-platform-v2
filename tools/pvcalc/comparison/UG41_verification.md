# UG-41 확인 요청 — 코드북 대조 필요 항목

`pvcalc.nozzle.weld_strength()` 구현 중 **공개 자료만으로 확정하지 못한 항목**입니다.
ASME VIII-1 코드북(UG-41, Fig. UG-41.1, UW-15)을 보고 아래 4건만 확인해 주시면
경로별 대조까지 마무리할 수 있습니다.

확인 방법: 각 항목의 「구현값」이 코드북과 같으면 ✅, 다르면 맞는 식을 적어주세요.

---

## 1. 총 용접하중 W

구현값:

```
W = (A − A1 + 2·tn·fr1·(E1·t − F·tr)) · Sv        ※ 음수면 0으로 처리
```

**미해결**: COMPRESS 데모 리포트(Codeware, SA-105 NPS 6 패드 노즐, P=100.18 psi)
숫자로 검산했더니 재현되지 않았습니다.

| 항목 | COMPRESS | 위 식 적용 |
|---|---|---|
| A | 0.5865 in² | 0.5865 ✅ (= d·tr, d=6.065, tr=0.0967) |
| A1 | 0.5508 in² | 0.5507 ✅ |
| **W** | **1,580.97 lbf** | **1,732 lbf ❌ (+9.6%)** |

W를 1,580.97로 맞추려면 둘째 항의 `tn`이 0.2383"이어야 하는데, 공칭 0.28"·
부식여유 0"·배관공차 적용값 0.245" 어느 것과도 맞지 않습니다.

→ **확인 요청**: 위 식이 맞습니까? 특히 둘째 항이 `2·tn·fr1·(E1·t − F·tr)`인지,
아니면 다른 형태인지.

## 2. 경로별 하중 W1-1 / W2-2 / W3-3

구현값:

```
W1-1 = (A2 + A5 + A41 + A42) · Sv
W2-2 = (A2 + A3 + A41 + A43 + 2·tn·t·fr1) · Sv
W3-3 = (A2 + A3 + A5 + A41 + A42 + A43 + 2·tn·t·fr1) · Sv
```

**미해결**: 같은 COMPRESS 케이스에서 위 세 식을 연립하면 A42 ≈ 0.0006 in²
(각장 0.024")가 나옵니다. 실제 각장(0.1339")과 맞지 않아 면적 조합 자체가
틀렸다고 판단했습니다.

→ **확인 요청**: 각 식의 면적 조합.

## 3. Fig. UG-41.1 경로 구성 — **이것이 핵심**

각 경로가 어느 용접 요소를 지나가는지. 구현에서 계산해 둔 요소는 6개입니다:

| 기호 | 요소 | 강도 식 |
|---|---|---|
| `e_wall` | 노즐벽 전단 | π/2 · (d+tn) · tn · 0.70 · Sn |
| `e_f41` | 외측 노즐 필릿 (leg 41) | π/2 · (d+2tn) · leg41 · 0.49 · S |
| `e_f42` | 패드 외경 필릿 (leg 42) | π/2 · Dp · leg42 · 0.49 · S |
| `e_f43` | 내측 필릿 (leg 43) | π/2 · (d+2tn) · leg43 · 0.49 · S |

| `e_g_pad` | 노즐–패드 그루브 인장 | π/2 · (d+2tn) · gr_pad · 0.74 · S |

## 4. 합격 판정 기준

경로 강도를 무엇과 비교합니까?

- (a) 해당 경로의 하중 `W_x-x`만
- (b) `W`와 `W_x-x` 중 **작은** 값
- (c) `W`와 `W_x-x` 중 **큰** 값

→ **확인 요청**: (a)/(b)/(c) 중 하나.

## 확정된 사항 (확인 불필요)

아래는 여러 출처가 일치해 그대로 구현했습니다.

- **UW-15(c) 용접 허용응력** (모재 허용응력 대비 백분율):
  그루브 인장 74% · 그루브 전단 60% · 필릿 전단 49% · 노즐벽 전단 70%
- **전단/인장 면적**: 원주의 절반 → `π/2 · D · 치수`
- 필릿·그루브 용접은 접합 두 재질 중 **약한 쪽** 허용응력 적용
  (코드 문구는 "vessel material" 기준이나, 상용 SW 관행 및 보수측에 맞춤)
- **외압 조건에서는 용접부 강도 계산 불필요** (COMPRESS 리포트에서 확인)
- **UW-15(b)(1) 면제** 존재
