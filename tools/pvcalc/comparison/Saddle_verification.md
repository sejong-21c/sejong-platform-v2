### 2. 참고 구현(thepvguy/calctoys)에서 발견한 오타 1건

분모에 연산자 우선순위 오류가 있습니다. **pvcalc는 고쳐서 구현했습니다.**

```python
# 원본 — sin(2β)·β/4 로 계산됨
den = 2π*((sinβ/β)**2 - 0.5 - (math.sin(2.0*self.beta) / 4.0 * self.beta))
# 수정 — sin(2β)/(4β)
den = 2π*((sinβ/β)**2 - 0.5 - math.sin(2.0*self.beta) / (4.0*self.beta))
```

근거: 같은 항이 `calcK6`의 `term7`에 `0.25 * sin(2β)/β`로 올바르게 들어가
있습니다. 그리고 θ=120°에서 수정판은 K8 = 0.340474 (공표 0.3399, +0.17%),
원본은 0.194741 (**−43%**)입니다.
