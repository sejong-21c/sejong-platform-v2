# 국내 기준 구현 노트 — 에너지공단 KPM / 가스안전공사 KGS AC111

원문 대조 기록 (2026-08-05). **원문 자체는 저작물이므로 이 문서에 조항 본문을
전재하지 않는다** — 구현에 필요한 구조·기호 정의·ASME 와의 차이만 남긴다.

## 1. 확보한 원문

| 기준 | 문서 | 상태 |
|---|---|---|
| 에너지공단 | 「압력용기 제조기술 규격 2002」 KEMCO CODE Section IV (KPM), 523p | 부장님 제공 (사내 보관) |
| 가스안전공사 | KGS AC111 (2023) 「고압가스용 저장탱크 및 압력용기 제조의 시설·기술·검사 기준」, 204p | cyber.kgs.or.kr 무료 열람본 |

> 따라서 **허용응력표(σa)·이음효율표(η)·외압 차트는 저장소에 담지 않는다.**
> ASME Sec II-D 를 내장하지 않는 것과 같은 원칙.

## 2. 두 기준의 계산식 계보가 같다 (중요)

KPM 과 AC111 은 **동일한 계산식 계보**(JIS B 8265 / KS 계열)를 쓴다. 기호도
같다 — σa(허용응력), η(용접이음매효율), W·V(경판 형상계수), 두꺼운 벽 판정에
원통 1/4·구형 0.178, 플랜지 보강에 15%(3mm 하한).

**그래서 ASME 와도 대수적으로 같은 식이 많다.** 예:

```
KPM-3221(1) / AC111 (1-1-1)   t = P·Di/(2σaη − 1.2P)
= P(2R)/(2σaη − 1.2P) = P·R/(σaη − 0.6P)   ← ASME UG-27(c)(1) 과 동일 형태
```

경판도 같다 — KPM W = (3+√(R/r))/4 = ASME App.1-4(d) M,
KPM V = [2+(D/2h)²]/6 = ASME App.1-4(c) K.

**따라서 기준 간 차이는 「식」이 아니라 「σa·η 의 근거와 부수 규정」이다.**
값을 반드시 해당 기준의 표에서 가져와야 하며, ASME 값을 그대로 넣으면
식은 같아도 결과가 틀린다.

## 3. KPM vs AC111 — 반드시 구분할 차이

| 항목 | KPM (에너지공단) | AC111 (가스안전공사) |
|---|---|---|
| 식의 α(부식여유) 항 | **식에 포함** (`… + α`) | **없음** — 부식여유는 별도 취급 |
| P 의 정의 | **최고사용압력** (KPM-3164) | **설계압력** |
| Di 의 정의 | 부식여유를 **제외한** 안지름 | 동체의 안지름 |
| σa 단서 | 재료의 허용인장응력 | 설계온도에서의 허용응력. **용접부 허용응력이 모재보다 낮으면 용접부 값 적용** |
| 최소두께 규정 | KPM-3210: 탄소강·저합금강 2.5 mm, 고합금강·비철 1.5/2.5 mm | 별도 확인 필요 |
| 층성동체 | 없음 | **있음** (multi-layered shell) — 아래 주의 |
| 원추형 동체 | KPM-3260 (미구현) | (3-1) `t = P·Di/(2cosθ(σaη − 0.6P))` |

⚠ **α 기호 충돌** — KPM 에서 α 는 부식여유(mm)지만, AC111 층성동체 식에서
α 는 **설계온도에 따른 수정계수**(−30~50℃ 1, 50~150℃ 1−(θ−50)/1000,
150~350℃ 0.9)다. 같은 글자가 완전히 다른 뜻이므로 코드에서 절대 공유하지 말 것.

⚠ **AC111 은 ASME 재료를 명시적으로 허용한다** — §3.2.4(1): ASME Sec II Part D
Table 1A·1B·3 의 허용인장응력을 조건부로 사용 가능. 즉 KGS 인허가에서
ASME 재료 데이터를 쓰는 경로가 열려 있다(조건 확인 필요). 반면 자체
**부록 A(허용인장응력)** 표도 가지고 있다.

## 5. AC111 — 다음에 구현할 것 (원문 확보 완료)

확인한 조항 (문서 p.13~14 = §3.3.1.1):

- (1-1-1) 원통동체 얇은 벽 / (1-1-2) 최소두께 > 안지름 1/4 인 경우
- (1-2) **층성동체** — 내통·층성부·외통 3층의 항복점·두께로 계산, 온도 수정계수 α,
  합성 용접이음매효율 η. KPM 에 없는 항목이라 별도 구현 필요
- (2-1)(2-2) 구형동체 (0.178 기준)
- (3-1) 원추부 / (3-2) 큰지름쪽 가장자리 둥근부위
- 식(3.10)(3.11) 관판 최소두께, 식(3.16)(3.17) 평판
- 접시형·반타원체형 경판 (p.26~27, 아직 정밀 대조 안 함)

작업 순서 제안: 원통·구형·원추 → 경판 → 층성동체 → 관판·평판.
`pvcalc/kec.py` 와 **식을 공유하지 말고 별도 모듈**(`pvcalc/kgs.py`)로 둘 것 —
α 의 뜻과 P 의 정의가 달라 한 함수로 묶으면 조용히 틀린 값이 나온다.

3. **KS B 6716** (압력용기의 관판) 사본 — 열교환기 관판 구현에 필요.
