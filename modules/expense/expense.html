🤖 AI 영수증 자동 인식

여러 장의 영수증을 한꺼번에 올리면 AI가 일자·금액·사용처·내역을 자동으로 추출하여 한 건씩 등록할 수 있게 정리해줍니다. (먼저 ⑦ AI 설정 탭에서 API 키와 사용 카드를 지정해주세요)
※ 한 PDF 파일에 여러 영수증이 들어 있어도 모두 분리하여 개별 인식합니다 (다중 페이지 PDF, 한 페이지에 여러 영수증 모두 지원).

💡 영수증 인식 정확도 향상 가이드
① 가능하면 영수증 1장당 1개 파일로 업로드 (자르기 정확도 100%)
② 여러 영수증을 한 페이지에 스캔할 때는 영수증 사이에 충분한 흰 여백 확보
③ 영수증을 똑바로 정렬하여 스캔 (기울어지면 자르기 어려움)
④ 영수증이 서로 겹치지 않도록 배치
⑤ 자르기가 부정확하면 미리보기 표에서 "✂ 영역 조정" 버튼으로 직접 영역 다시 선택 가능
📎 영수증 이미지를 끌어다 놓거나 클릭하여 일괄 선택

AI 설정

AI 제공자 선택

Claude API 설정

API 키는 console.anthropic.com에서 발급. 정확한 모델 ID는 위의 "📋 사용 가능 모델 조회" 버튼으로 확인하세요.

Gemini API 설정

API 키는 aistudio.google.com에서 발급.
⚠ Gemini 3.x 의 정확한 모델 ID는 시기에 따라 변경됩니다. "📋 사용 가능 모델 조회" 버튼으로 실시간 확인하세요.

⚠ 보안 안내: API 키는 브라우저 메모리에만 저장되며 외부로 전송되지 않습니다 (AI 호출 시 해당 제공자에게만 전송). 페이지를 새로고침하면 키를 다시 입력해야 합니다. JSON 백업에는 키가 포함되지 않습니다.

AI 인식 동작 방식

  • 업로드된 모든 영수증을 한 번의 호출로 일괄 분석합니다 (비용·시간 절감).
  • 추출 항목: 일자, 금액, 사용처(상호), 사용 내역(품목/카테고리), 출장장소 추론, 인원 추론
  • 출장장소는 ③ 출장지/거래처 리스트와 비교하여 자동 매칭합니다. 매칭이 어렵거나 영수증에 정보가 없는 경우 빈칸으로 둡니다.
  • 인원은 영수증에 인원 표기가 있거나 메뉴 수량으로 추정 가능한 경우만 채우고, 그 외는 빈칸으로 둡니다.
  • 추출 결과는 미리보기 후 "내역 등록" 버튼을 눌러야 실제로 저장됩니다 (사용자가 검토·수정 가능).
