지금 어디까지 왔나. 직원 개방 세 칸(사용자별 장부 · 개인 API 열쇠 · 개인 구독 연결)이 다 찼다. 직원은 메신저 AI 비서로 플랫폼을 말로 고치고(행위 열하나 — 캘린더 일정·부서 스케줄까지), 자기 Claude·ChatGPT 로 회사 규격·NAS 파일과 원본을 자기 부서 범위에서 찾아 읽는다(개인 자료 폴더는 본인만). 백업은 사본 셋(맥 · 드라이브 · R2), 맥 백업은 매일 전체 대조. 남은 큰 줄기는 연말 유료 전환 판단이고, ChatGPT 확인은 회사 GPT 계정을 산 뒤 맨 끝에 한다. "NCR 원인별로" 같은 수치 질문은 이제 표·차트로 답한다. 작업 기록은 매달 1일 저절로 떼어 낸다. 옛 한글·워드·엑셀 문서도 이제 읽는다.

1. 직원도 자기 부서 파일을 찾아 읽는다완료 9/25개인 자료는 본인만
지금 직원 연결에는 볼트 검색이 없어 파일 카드를 못 찾고, 원본 읽기도 super 만 된다. 부서 범위로 거른 파일 검색 + 원본 읽기를 직원에게 연다 (개인 노트·도면색인·인사 자료는 표 밖이라 그대로 안 나간다). BYO 가 "규격만 되는 연결" 에서 "내 부서 자료가 되는 연결" 이 된다.
9/25 완료 — 직원은 자기 부서·전사 카드와 원본, 개인 자료 폴더는 본인만(super 도 예외 없음). 메신저 AI 도 같은 규칙. 맥 실측: 기술부 직원이 "개인 자료 김철우 차장" 을 대놓고 찾아도 0건. 한글 분해형(NFD) 경로에서 규칙이 빗나가던 구멍을 직원 연결 0명일 때 잡아 막았다.
2. 읽기 한도 뒤처리 셋완료 9/25b100

9/25 완료 — 브라우저 한도 표시(browserLimitHitAt) · 접속마다 sessions · 맥 백업 매일 전체 대조(거울 정확: messages 3,569/3,569 · activityLog 616/616).
4. 한글(.hwp) · 옛 워드(.doc) 읽기완료 9/25무료 · 맥

9/25 완료 — .hwp 는 직접 푸는 작은 해석기(olefile), .doc 는 맥 기본 textutil. 특근 보고서·준공계·시방서 실측 40~90ms. 파이스와 직원 연결(원본 읽기)이 같이 쓴다. 남은 것: 옛 파워포인트(.ppt).

9/25 완료 — 일정등록: 화면과 같은 꼴로 캘린더에(구글 연결 시 거기도) · 부서스케줄: 부서 자체 업무 끝에 한 줄, 부서장·관리자급만, Rev·이력까지. 없는 날짜(2/30)·모르는 분류는 고치지 않고 거절. 사람 손 시험 완료 — 말로 시켜도 카드가 맞게 뜬다("다음 주 화요일" → 9/29).
